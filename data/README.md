
# Synthetic Maternal Telehealth Datasets

This directory contains synthetic datasets generated for the
AI for Attendance portfolio project.

## Original Dataset
`maternal_telehealth_full_dataset.csv`

The original synthetic dataset generated before the
final cleaning and preparation process.

## Cleaned Dataset
`maternal_telehealth_data_clean.csv`

The validated dataset used for exploratory analysis
and subsequent predictive modeling.

- 10,150 observations
- 19 columns
- 324 no-show appointments
- 3.19% no-show rate
- Zero exact duplicate records

## Data Privacy

All patient records and appointment information are
synthetically generated for educational and portfolio
purposes. No real patient data is included.
